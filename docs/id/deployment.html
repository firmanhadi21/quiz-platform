Administrasi & Server

Deploy & Operasional Server

Referensi lengkap variabel lingkungan .env, penyedia AI, kuis contoh bawaan, reverse proxy Nginx, pencadangan harian otomatis, pemulihan, dan pembaruan aman.

Variabel lingkungan (.env)

Pengaturan server disimpan di deploy/.env. Jaga kerahasiaan berkas ini (chmod 600 .env) karena berisi kunci API AI. Pengaturan yang bertanda Halaman Admin berlaku sebagai nilai awal dan dapat diubah nanti langsung dari menu Admin.

VariabelBawaan / ContohHalaman AdminKeterangan
DOMAINquiz.example.sch.idTidakAlamat domain publik untuk sertifikat HTTPS otomatis Caddy
ADMIN_EMAIL, ADMIN_NAMEadmin@example.sch.idTidakAdmin pertama yang dibuat otomatis oleh ./install.sh jika belum ada admin
QUIZ_SITE_NAMEQuizYaNama situs di bilah atas dan tab peramban
QUIZ_ORG(kosong)YaNama lembaga / sekolah
QUIZ_COLOR_PRIMARY#0f6b5fYaWarna utama heksadesimal (turunan terang/gelap dihitung otomatis)
QUIZ_COLOR_ACCENT#f0b429YaWarna aksen heksadesimal
QUIZ_REGISTRATIONopenYaopen (terbuka) atau closed (hanya admin)
QUIZ_DEFAULT_ROLEstudentYaPeran pendaftar baru: student atau teacher
QUIZ_SEEDoff (di .env.example)TidakIsi on untuk memuat kuis contoh JSON dari QUIZ_SEED_DIR ke pustaka publik sekali saja
QUIZ_SEED_DIR/app/seedTidakFolder khusus berisi berkas kuis *.json yang di-mount ke kontainer
QUIZ_AI_URLhttps://api.deepseek.com/v1TidakAlamat dasar API kompatibel OpenAI

TZAsia/JakartaTidakZona waktu tanggal pada laporan dan ekspor CSV

QUIZ_DATA/data (Docker)TidakDirektori penyimpanan quiz.db, uploads/, brand/, dan backups/

Setelah menyunting deploy/.env, terapkan perubahan dengan menjalankan ./install.sh atau docker compose up -d.

Mengatur penyedia AI

Semua layanan AI yang menyediakan endpoint /chat/completions bergaya OpenAI dapat digunakan:

PenyediaQUIZ_AI_URLContoh QUIZ_AI_MODEL
DeepSeekhttps://api.deepseek.com/v1deepseek-v4-flash
OpenAIhttps://api.openai.com/v1gpt-5-mini
OpenRouterhttps://openrouter.ai/api/v1deepseek/deepseek-chat

Setiap permintaan AI ditagihkan ke QUIZ_AI_KEY. Pembatasan bawaan per akun guru (5 permintaan / 5 menit dan 40 / hari) mencegah pemakaian berlebih.

Memuat kuis contoh milik sendiri

Ekspor kuis dalam format JSON dari halaman kuis, letakkan berkas .json di sebuah folder, mount folder tersebut ke kontainer (mis. /seed), lalu atur QUIZ_SEED=on dan QUIZ_SEED_DIR=/seed. Setiap berkas dimuat satu kali sebagai kuis publik baca-saja yang bisa langsung dimainkan atau disalin oleh siapa saja.

Memakai Nginx yang sudah ada (pengganti Caddy)

Jika server Anda sudah menjalankan Nginx di port 80/443:

  1. Jalankan hanya kontainer aplikasi di localhost

    Tambahkan ports: ["127.0.0.1:8000:8000"] pada layanan quiz di deploy/docker-compose.yml, lalu jalankan:

    bash
    docker compose up -d --build quiz
  2. Gunakan konfigurasi contoh deploy/nginx.example.conf

    Pastikan tiga bagian penting berikut tetap dipertahankan:

    • location /ws/ — header upgrade WebSocket dan proxy_read_timeout 3h agar koneksi kuis langsung tetap stabil.
    • location /api/ai/ — client_max_body_size 51m (untuk berkas PDF/PPTX hingga 50 MB) serta proxy_read_timeout 300s.
    • Batas rate-limit longgar (burst=600 nodelay) karena satu kelas sering berbagi satu alamat IP NAT kampus/sekolah.

Pencadangan & pemulihan data

Seluruh data tersimpan pada volume Docker quiz_quiz-data (di-mount ke /data): quiz.db, uploads/, brand/, dan backups/.

Menjalankan pencadangan saat situs aktif

manage.py backup memanfaatkan API backup daring SQLite (aman dijalankan tanpa menghentikan situs), mengemas quiz.db, uploads/, dan brand/ ke dalam arsip .tar.gz di /data/backups, serta otomatis menyimpan 14 arsip terbaru.

bash
# Jalankan cadangan manual
docker compose exec quiz python manage.py backup

# Salin arsip cadangan ke luar kontainer
docker compose cp quiz:/data/backups ./backups

Jadwalkan cadangan rutin tiap malam dengan cron

cron
0 2 * * * cd /path/to/quiz-platform/deploy && docker compose exec -T quiz python manage.py backup

Memulihkan dari arsip cadangan

bash
cd /path/to/quiz-platform/deploy
docker compose stop quiz
docker compose run --rm -v "$PWD/backups:/b:ro" quiz \
  tar xzf /b/quiz-YYYYMMDD-HHMMSS.tar.gz -C /data
docker compose start quiz

Pembaruan & melihat log

bash
# Pantau log aplikasi secara langsung
docker compose logs -f quiz

# Perbarui ke versi terbaru (seluruh data di quiz_quiz-data tetap aman)
cd /path/to/quiz-platform
git pull
cd deploy && ./install.sh

Lakukan pembaruan di luar jam kelas

Pembaruan menjaga seluruh basis data, gambar, dan identitas situs tetap utuh, namun memulai ulang kontainer akan memutus kuis langsung yang sedang berjalan (jawaban yang sudah terkirim tetap tersimpan).

Daftar periksa sebelum serah terima (sekolah / klien)

  • Lisensi: Kode berlisensi MIT; pertahankan pemberitahuan hak cipta dalam kode.
  • Data pribadi: Nama, email, dan nilai siswa tersimpan di server lembaga. Sepakati kebijakan penyimpanan data dan siapa yang memegang akses Admin.
  • Pemulihan admin: Pastikan minimal satu admin sudah mengganti kata sandi awal dan mengetahui cara mengatur ulang kata sandi pengguna.
  • Cadangan terverifikasi: Pastikan cron pencadangan harian berjalan dan arsip disalin berkala ke luar server.
