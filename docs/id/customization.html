Kustomisasi & Pengembangan

Peta kode sumber, alur pengembangan lokal, titik kustomisasi yang rapi, cara menjalankan pengujian otomatis, serta arsitektur keamanan.

Lingkungan pengembangan lokal

Quiz Platform tidak memerlukan bundler frontend atau proses build Node — cukup sunting berkas di app/ lalu muat ulang peramban.

bash
cd quiz-platform
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt pytest

# Buat admin lokal (data tersimpan di ./data/)
.venv/bin/python app/manage.py create dev@contoh.org "Dev Admin" admin

# Jalankan dengan auto-reload (selalu satu worker!)
cd app && QUIZ_SECURE_COOKIE=0 ../.venv/bin/uvicorn main:app --reload --port 8765

Buka http://127.0.0.1:8765. Berkas statis dikirim dengan Cache-Control: no-cache sehingga perubahan JavaScript dan CSS langsung terlihat saat halaman dimuat ulang.

Titik kustomisasi kode

Utamakan .env dan halaman Admin untuk perbedaan antar-klien

Pertahankan satu basis kode untuk seluruh sekolah atau klien, lalu simpan perbedaan (nama, logo, warna, pendaftaran, kunci AI) di .env dan halaman Admin agar pembaruan tetap mudah.

Menjalankan pengujian

Jalankan rangkaian uji sebelum rilis atau sebelum menerapkan perubahan ke produksi:

bash
# 1. Uji API & logika (akun, kuis, permainan, AI, anti-curang, roda putar, identitas situs)
.venv/bin/pytest -q

# 2. Uji peramban E2E dengan Playwright (guru + siswa menjalani satu sesi penuh)
PLAYWRIGHT=/path/to/node_modules/playwright/index.mjs tests/run_e2e.sh [folder-tangkapan-layar]

GitHub Actions (.github/workflows/tests.yml) otomatis menjalankan pytest -q dan memeriksa pembangunan kontainer Docker pada setiap push dan pull request.

Arsitektur keamanan & keandalan

  • Hash kata sandi: scrypt (N=16384, r=8, p=1) dengan salt acak 16-byte dan perbandingan waktu konstan.
  • Sesi aman: Token acak 32-byte disimpan dalam bentuk hash SHA-256 di SQLite, dikirim melalui cookie HttpOnly, SameSite=Lax, dan Secure (masa berlaku 30 hari).
  • Perlindungan CSRF: Setiap permintaan tulis ke /api/* mewajibkan header khusus X-Quiz: 1 yang diblokir lintas-situs oleh peramban tanpa CORS preflight.
  • Validasi asal WebSocket: Koneksi WebSocket memverifikasi kesesuaian Origin dengan Host.
  • Header keamanan ketat: Content Security Policy (script-src 'self', frame-ancestors 'none'), X-Content-Type-Options: nosniff, Referrer-Policy: same-origin, serta HSTS melalui Caddy/Nginx.
  • Kontainer non-root: Image Docker berjalan sebagai pengguna non-root 1000:1000 dengan satu worker Uvicorn (--workers 1) agar status permainan langsung di memori tetap konsisten.
