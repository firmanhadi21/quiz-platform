Administrasi & Server

Administrasi & Identitas Situs

Kelola akun pengguna, peran, pendaftaran, warna dan logo situs dari panel Admin, atau jalankan perintah pengelolaan server melalui app/manage.py.

Membuka panel Admin

Masuk dengan akun Admin lalu klik Admin di bilah navigasi atas (/admin). Bagian ringkasan atas menampilkan jumlah total akun, Guru, Siswa, Admin, Kuis, dan Permainan yang pernah dijalankan.

Mengubah identitas situs (nama, warna & logo)

Pada kartu Identitas situs, Anda dapat menyesuaikan tampilan Quiz Platform agar sesuai identitas sekolah atau kampus tanpa mengubah kode. Perubahan langsung berlaku untuk semua pengguna:

  • Nama situs: Tampil di bilah atas dan judul tab peramban (maks. 60 karakter).
  • Lembaga: Nama sekolah, jurusan, atau institusi (opsional, maks. 120 karakter).
  • Warna utama & Warna aksen: Pilih warna kode heksadesimal (#rrggbb). Turunan warna terang dan gelap dihasilkan otomatis lewat /brand.css. Klik Warna bawaan kapan saja untuk kembali ke warna hijau teal (#0f6b5f) dan kuning amber (#f0b429).
  • Logo: Klik Unggah logo untuk mengunggah berkas PNG, JPG, atau WebP maks. 1 MB (SVG ditolak demi keamanan). Setiap unggahan memakai nama berkas unik agar peramban tidak menampilkan cache logo lama.

Pengaturan pendaftaran & peran bawaan

Pada kartu Pengaturan situs, atur cara pengguna baru bergabung:

  • Pendaftaran terbuka: Jika dicentang, siapa saja dapat membuat akun di /register. Matikan opsi ini jika akun baru hanya boleh dibuat oleh Admin.
  • Peran akun yang baru mendaftar:
    • Siswa (disarankan untuk sekolah/kampus): Pendaftar baru langsung menjadi siswa; Admin menaikkan akun guru secara manual.
    • Guru: Siapa pun yang mendaftar langsung bisa membuat kuis, memandu permainan, dan memakai Pembuat Soal AI.

Mengelola akun pengguna

Pada bagian Akun, Anda dapat mencari pengguna berdasarkan nama atau email, menyaring menurut peran atau status (Semua, Siswa, Guru, Admin, Nonaktif), serta melakukan tindakan berikut:

  • + Tambah pengguna: Buat akun dengan nama, email, dan peran. Kata sandi sementara hanya ditampilkan satu kali untuk Anda berikan ke pengguna.
  • Ubah peran: Ganti peran pengguna antara Siswa, Guru, dan Admin langsung dari menu tarik-turun.
  • Atur ulang sandi: Membuat kata sandi sementara baru dan langsung menghentikan seluruh sesi aktif pengguna tersebut.
  • Nonaktifkan / Aktifkan: Menonaktifkan akun akan memblokir login dan mengeluarkan semua sesi tanpa menghapus kuis atau riwayat permainan.
  • Hapus: Menghapus akun secara permanen beserta seluruh kuis, permainan, dan roda putar miliknya.

Pengaman agar tidak terkunci sendiri

Anda tidak dapat mengubah peran, menonaktifkan, atau menghapus akun admin milik Anda sendiri sehingga situs tidak akan pernah kehilangan admin.

Referensi perintah CLI server (app/manage.py)

Semua tugas administrasi akun — beserta pencadangan SQLite yang aman saat situs berjalan — juga tersedia lewat terminal server di folder deploy/:

bash
# Daftar seluruh pengguna, peran, jumlah kuis, dan status nonaktif
docker compose exec quiz python manage.py users

# Buat akun baru (peran: student | teacher | admin) — mencetak sandi sementara
docker compose exec quiz python manage.py create guru@sekolah.sch.id "Ani Wijaya" teacher

# Ubah peran pengguna (mis. jadikan admin)
docker compose exec quiz python manage.py role guru@sekolah.sch.id admin

# Atur ulang kata sandi yang lupa (otomatis menutup sesi aktif)
docker compose exec quiz python manage.py reset-password admin@sekolah.sch.id

# Nonaktifkan sementara atau aktifkan kembali akun
docker compose exec quiz python manage.py disable pengguna@sekolah.sch.id
docker compose exec quiz python manage.py enable pengguna@sekolah.sch.id

# Hapus akun beserta seluruh kuis, permainan, dan roda miliknya
docker compose exec quiz python manage.py delete pengguna@sekolah.sch.id

# Buat arsip cadangan konsisten di /data/backups (menyimpan 14 terbaru)
docker compose exec quiz python manage.py backup

Saat berjalan lokal tanpa Docker, jalankan .venv/bin/python app/manage.py <perintah> dari direktori utama repositori.
