Panduan Cepat

Jalankan Quiz Platform dalam hitungan menit — baik di server Linux produksi dengan HTTPS otomatis melalui Docker + Caddy, maupun secara lokal di komputer Anda.

Opsi A: Server produksi dengan Docker (5 menit)

Ini adalah cara yang disarankan untuk sekolah, jurusan kampus, atau lembaga.

Prasyarat:

  • Server Linux yang sudah terpasang Docker dan Docker Compose plugin (1 CPU dan 1 GB RAM sudah memadai).
  • Nama domain dengan DNS A/AAAA yang sudah mengarah ke server tersebut, serta port 80 dan 443 terbuka.
  • Opsional: Kunci API (API key) dari layanan AI kompatibel OpenAI (DeepSeek, OpenAI, OpenRouter) untuk mengaktifkan Pembuat Soal AI.
  1. Kloning repositori dan buat berkas .env

    Jalankan ./install.sh pertama kali. Skrip akan menyalin .env.example menjadi .env dengan izin chmod 600 lalu berhenti agar Anda dapat mengisinya.

    bash
    git clone https://github.com/firmanhadi21/quiz-platform.git
cd quiz-platform/deploy
./install.sh
  2. Sunting .env dengan domain dan akun admin pertama

    Buka .env (misalnya nano .env) lalu isi minimal DOMAIN dan ADMIN_EMAIL. Isi juga QUIZ_AI_KEY bila ingin mengaktifkan Pembuat Soal AI.

    dotenv
    DOMAIN=kuis.sekolahanda.sch.id
ADMIN_EMAIL=admin@sekolahanda.sch.id
ADMIN_NAME=Admin Sekolah

# Opsional: muat contoh kuis bawaan ke pustaka publik
QUIZ_SEED=on

# Opsional: aktifkan pembuat soal AI (kosongkan QUIZ_AI_KEY untuk mematikan)
QUIZ_AI_URL=https://api.deepseek.com/v1
QUIZ_AI_MODEL=deepseek-v4-flash
QUIZ_AI_KEY=sk-kunci-api-anda
  3. Bangun kontainer, jalankan, dan buat admin pertama

    Jalankan ./install.sh sekali lagi. Docker akan membangun aplikasi, Caddy otomatis mengurus sertifikat HTTPS, lalu skrip membuat akun admin pertama dan menampilkan kata sandi sementara.

    bash
    ./install.sh
  4. Masuk dan segera ganti kata sandi

    Buka https://<domain-anda>/login, masuk memakai kata sandi tersebut, lalu klik nama Anda di bilah atas (Akun saya) untuk menggantinya dengan kata sandi permanen.

Uji instalasi baru secara menyeluruh

Dari direktori deploy/, jalankan skrip pemeriksaan bawaan untuk menguji masuk akun, pembuatan kuis, dan permainan langsung melalui proxy HTTPS:

bash
docker run --rm --network host -v "$PWD/../tests/install_check.py:/t.py:ro" quiz-quiz \
  python /t.py https://<DOMAIN> <ADMIN_EMAIL> <PASSWORD>

Opsi B: Coba secara lokal (3 menit)

Ingin mencoba Quiz Platform di laptop tanpa Docker atau HTTPS? Cukup gunakan Python 3.12+ (atau Python 3.10+).

  1. Kloning repositori dan siapkan virtual environment
    bash
    git clone https://github.com/firmanhadi21/quiz-platform.git
cd quiz-platform
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt pytest
  2. Buat akun admin lokal pertama

    Perintah ini membuat basis data SQLite di data/quiz.db dan mencetak kata sandi acak.

    bash
    .venv/bin/python app/manage.py create anda@contoh.org "Nama Anda" admin
  3. Jalankan server lokal

    Gunakan QUIZ_SECURE_COOKIE=0 agar sesi masuk dapat bekerja di HTTP lokal tanpa HTTPS.

    bash
    cd app && QUIZ_SECURE_COOKIE=0 ../.venv/bin/uvicorn main:app --port 8765
  4. Buka di peramban

    Akses http://127.0.0.1:8765 lalu masuk di /login. Anda dapat berganti bahasa kapan saja dengan tombol ID / EN di pojok kanan atas.

Jangan gunakan QUIZ_SECURE_COOKIE=0 di server produksi

QUIZ_SECURE_COOKIE=0 hanya untuk pengujian HTTP lokal. Di produksi dengan HTTPS, biarkan nilai bawaannya (1).

Membuat & memainkan kuis pertama dalam 2 menit

Setelah masuk sebagai Guru atau Admin:

  1. Buat kuis baru

    Buka Dasbor lalu klik + Kuis baru. Isi judul (mis. Kartografi Dasar), tulis beberapa soal — atau pakai Tempel banyak soal maupun ✨ Buat dengan AI — lalu klik Simpan & tutup.

  2. Mulai kuis langsung

    Klik ▶ Mainkan pada kartu kuis, pastikan mode Kuis langsung terpilih, lalu tekan Mulai. Kode permainan 6 angka dan kode QR langsung tampil di layar guru.

  3. Gabung sebagai siswa

    Buka alamat situs di jendela peramban lain (atau di ponsel), masukkan kode 6 angka (atau pindai kode QR), ketik nama panggilan, lalu klik Gabung.

  4. Jalankan kuis dan lihat laporan

    Klik ▶ Mulai pada layar guru untuk menjalankan tiap soal dan menampilkan jawaban. Setelah podium akhir muncul, buka ▤ Dasbor hasil atau ▶ Bahas soal.
