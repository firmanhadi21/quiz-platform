Ringkasan

Quiz Platform adalah platform kuis kelas yang dapat di-host mandiri: kuis langsung di layar kelas, tugas mandiri, bacaan gaya TOEFL, pembuat soal AI, mode anti-curang, dasbor hasil, dan roda putar — dengan antarmuka Bahasa Indonesia dan English.

Apa itu Quiz Platform?

Quiz Platform dirancang untuk sekolah, program studi/jurusan kampus, lembaga pelatihan, maupun pengajar individu yang menginginkan aplikasi kuis interaktif di server sendiri — sehingga data nama siswa, nilai, dan materi ajar tetap berada di bawah kendali lembaga.

Aplikasi berjalan dalam satu kontainer Docker kecil berbasis FastAPI, SQLite (mode WAL), dan JavaScript murni tanpa proses build yang rumit. Satu server ringan (1 CPU, 1 GB RAM) cukup untuk menangani satu sekolah atau jurusan dengan beberapa ratus pemain sekaligus.

Fitur utama

▶

Kuis Langsung

Setiap permainan mendapat kode 6 angka dan kode QR. Guru memandu di layar proyektor sementara siswa menjawab dari ponsel. Jawaban benar lebih cepat mendapat poin lebih tinggi.

✎

Tugas Mandiri

Kuis yang sama dapat diberikan sebagai tugas asinkron dengan pilihan batas waktu per soal, tenggat waktu, serta pengacakan soal dan pilihan per siswa.

✨

Pembuat Soal AI

Tempel materi atau unggah PDF, DOCX, PPTX, atau TXT (maks. 50 MB), opsional dengan rubrik penilaian (CPMK). Mendukung API kompatibel OpenAI (DeepSeek, OpenAI, OpenRouter).

📖

Teks Bacaan

Cocok untuk latihan membaca (seperti TOEFL Reading): teks bacaan ditampilkan dulu tanpa waktu berjalan, lalu tetap mendampingi di samping setiap soal.

🛡

Mode Anti-Curang

Opsional per permainan. Mencatat perpindahan tab/aplikasi atau keluar layar penuh (dengan toleransi 2 detik), memblokir salin-tempel, serta menyediakan sanksi Catat, Nilai Nol, atau Kunci.

▤

Dasbor Hasil & Bahas Soal

Podium pemenang, histogram sebaran ketepatan, soal tersulit/termudah, tabel siswa & soal, kinerja per kriteria rubrik, unduh CSV, cetak/PDF, serta mode bahas soal.

◔

Roda Putar

Pilih siswa atau topik secara acak. Ketik langsung, ambil dari daftar pemain kuis, atau unggah daftar kelas Excel (.xlsx) / CSV (nomor dan nama).

⚙

Peran & Identitas Situs

Peran Siswa, Guru, dan Admin. Admin dapat mengelola akun, membuka/menutup pendaftaran, serta mengganti nama situs, lembaga, warna, dan logo langsung dari halaman web.

Batasan & catatan rancangan

  • Satu proses + SQLite: Cocok untuk satu sekolah, fakultas, atau jurusan (beberapa ratus pemain bersamaan; maksimal 500 pemain per permainan). Status giliran kuis langsung disimpan di memori, jadi jalankan selalu dengan --workers 1.
  • Tanpa pengiriman email otomatis: Pengaturan ulang kata sandi dilakukan langsung oleh Admin (lewat halaman Admin atau manage.py reset-password) yang menghasilkan kata sandi sementara sekali pakai.
  • Mode anti-curang berbasis peramban: Anti-curang mencatat saat siswa meninggalkan tab/aplikasi atau keluar layar penuh serta memblokir salin-tempel, namun peramban tidak dapat mencegah berpindah aplikasi secara fisik atau mendeteksi perangkat kedua.
