Administration & Hosting

Administration & Branding

Manage user accounts, roles, registration settings, site colors and logo from the Admin panel, or run server-side commands via app/manage.py.

Opening the Admin panel

Sign in with an Admin account and click Admin in the top navigation bar (/admin). The top summary bar displays live counts for total accounts, Teachers, Students, Admins, Quizzes, and Games hosted.

Customizing site identity & branding

Under Site identity, you can white-label Quiz Platform for your school or organization without editing any code. Changes take effect immediately for all users:

  • Site name: Shown in the header bar and browser tab (max 60 characters).
  • Organisation: Optional school or institution subtitle (max 120 characters).
  • Main colour & Accent colour: Pick any hex colors (#rrggbb). Quiz Platform automatically generates darker, deeper, and wash shades via /brand.css. Click Default colours anytime to restore teal (#0f6b5f) and amber (#f0b429).
  • Logo: Click Upload logo to upload a PNG, JPG, or WebP image up to 1 MB (SVG is rejected for security). Each upload receives a unique immutable filename so browsers update immediately without stale cache.

Registration & default role

Under Site settings, control how new accounts join your server:

  • Registration is open: When checked, anyone can sign up at /register. Turn this off if you want only Admins to create accounts.
  • Role of newly registered accounts:
    • Student (recommended for schools): New sign-ups can join games and practice; Admins promote teachers individually.
    • Teacher: Anyone who registers can immediately create quizzes, host games, and use the AI Question Writer.

Managing user accounts

In the Accounts section you can search by name or email, filter by role or status (All, Student, Teacher, Admin, Disabled), and perform these actions:

  • + Add user: Create an account with name, email, and role. A one-time temporary password is displayed once for you to hand to the user.
  • Change role: Switch any user between Student, Teacher, and Admin using the inline dropdown.
  • Reset password: Generates a new one-time password and immediately signs the user out of all active sessions.
  • Disable / Enable: Disabling an account blocks login and revokes all active sessions without deleting their quizzes or game records.
  • Delete: Permanently removes the account and cascades to all quizzes, games, and saved wheels they created.

Safety guard against locking yourself out

You cannot change the role of, disable, or delete your own admin account, ensuring the site can never be left without an administrator.

Server CLI reference (app/manage.py)

Every account administration chore — plus consistent live SQLite backups — can also be run from the server terminal inside deploy/:

bash
# List all users, roles, quiz counts, and disabled status
docker compose exec quiz python manage.py users

# Create a new account (role: student | teacher | admin) — prints one-time password
docker compose exec quiz python manage.py create teacher@school.edu "Ani Wijaya" teacher

# Change an existing user's role (e.g. promote to admin)
docker compose exec quiz python manage.py role teacher@school.edu admin

# Reset a lost password (also revokes active sessions)
docker compose exec quiz python manage.py reset-password admin@school.edu

# Temporarily disable or re-enable an account
docker compose exec quiz python manage.py disable user@school.edu
docker compose exec quiz python manage.py enable user@school.edu

# Permanently delete an account and all of its quizzes, games, and wheels
docker compose exec quiz python manage.py delete user@school.edu

# Create a consistent backup archive in /data/backups (keeps last 14)
docker compose exec quiz python manage.py backup

When running locally without Docker, invoke .venv/bin/python app/manage.py <command> from the repository root.
