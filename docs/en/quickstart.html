Getting Started

Quickstart

Get Quiz Platform running in minutes — either on a production Linux server with automatic HTTPS via Docker + Caddy, or on your laptop for local evaluation.

Option A: Production server with Docker (5 minutes)

This is the recommended setup for a school, university department, or organization.

Prerequisites:

  • A Linux server with Docker and the Docker Compose plugin (1 CPU and 1 GB RAM is sufficient).
  • A domain name whose DNS A/AAAA record already points to your server, with ports 80 and 443 open.
  • Optional: An API key for an OpenAI-compatible AI provider (DeepSeek, OpenAI, OpenRouter) to enable the AI Question Writer.
  1. Clone the repository and generate .env

    Run ./install.sh once. On its first run, it copies .env.example to .env with chmod 600 permissions and exits so you can edit it.

    bash
    git clone https://github.com/firmanhadi21/quiz-platform.git
cd quiz-platform/deploy
./install.sh
  2. Edit .env with your domain and first admin

    Open .env in your editor (e.g. nano .env) and set at least DOMAIN and ADMIN_EMAIL. Add QUIZ_AI_KEY if you want the AI Question Writer enabled.

    dotenv
    DOMAIN=quiz.yourschool.edu
ADMIN_EMAIL=admin@yourschool.edu
ADMIN_NAME=School Admin

# Optional: load the built-in starter quizzes into the public library
QUIZ_SEED=on

# Optional: enable AI question writer (leave QUIZ_AI_KEY empty to disable)
QUIZ_AI_URL=https://api.deepseek.com/v1
QUIZ_AI_MODEL=deepseek-v4-flash
QUIZ_AI_KEY=sk-your-key-here
  3. Build, start, and create the first admin

    Run ./install.sh a second time. Docker builds the container, Caddy obtains and renews the HTTPS certificate automatically, and the script creates your first admin account and prints its one-time password.

    bash
    ./install.sh
  4. Sign in and change your password

    Open https://<your-domain>/login, sign in with the printed password, then click your name in the top navigation bar (My account) to set your own permanent password.

Verify a fresh install end-to-end

Run the built-in smoke check from deploy/ to verify sign-in, quiz creation, and a live WebSocket game through your HTTPS proxy:

bash
docker run --rm --network host -v "$PWD/../tests/install_check.py:/t.py:ro" quiz-quiz \
  python /t.py https://<DOMAIN> <ADMIN_EMAIL> <PASSWORD>

Option B: Try it locally (3 minutes)

Want to test Quiz Platform on your own computer without Docker or HTTPS? Use Python 3.12+ (or Python 3.10+).

  1. Clone and create a virtual environment
    bash
    git clone https://github.com/firmanhadi21/quiz-platform.git
cd quiz-platform
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt pytest
  2. Create your first local admin account

    The command creates the SQLite database in data/quiz.db and prints a generated password.

    bash
    .venv/bin/python app/manage.py create you@example.org "Your Name" admin
  3. Start the local server

    Set QUIZ_SECURE_COOKIE=0 so login cookies work over plain HTTP on localhost.

    bash
    cd app && QUIZ_SECURE_COOKIE=0 ../.venv/bin/uvicorn main:app --port 8765
  4. Open in your browser

    Visit http://127.0.0.1:8765 and sign in at /login. Toggle between English and Bahasa Indonesia anytime with the EN / ID button in the top-right corner.

Never set QUIZ_SECURE_COOKIE=0 in production

QUIZ_SECURE_COOKIE=0 is strictly for local HTTP testing. In production over HTTPS, leave it unset (defaults to 1).

Your first quiz in 2 minutes

Once signed in as a Teacher or Admin:

  1. Create a quiz

    Open Dashboard and click + New quiz. Give it a title (e.g. Introduction to Geography), add a couple of questions — or click Paste many questions or ✨ Write with AI — then click Save & close.

  2. Host a live game

    Click ▶ Host on your quiz card, keep Live quiz selected, and press Start. A 6-digit game code and QR code appear on the projector screen.

  3. Join as a student

    Open the site in a second browser window (or on your phone), type the 6-digit code (or scan the QR code), enter a nickname, and click Join.

  4. Run the game and view the report

    Click ▶ Start on the host screen to advance through questions and answer reveals. When the final podium appears, click ▤ Results dashboard or ▶ Review questions.
