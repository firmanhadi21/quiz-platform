Teacher How-To

A complete guide for teachers and lecturers on writing, importing, organizing, and generating quizzes with the editor, reading passages, and the AI Question Writer.

Teacher dashboard & quiz library

When signed in with a Teacher or Admin account, Dashboard shows two sections:

  • My quizzes: All quizzes you own, with quick actions to Host, Edit, Duplicate, Practice, or Delete. Deleting a quiz preserves reports of past games because every game stores its own snapshot of the questions.
  • My games: Your 100 most recent live quizzes and assignments, with live status (Open / Ended), player count, and links to Open host screen or Report.

To browse shared quizzes, open Explore in the top navigation bar. You can search by title, subject, or description, host any public quiz immediately, or click Duplicate to make your own editable copy.

Creating & editing quizzes

Click + New quiz on the Dashboard (or Edit on any quiz you own). Every quiz can hold 1 to 200 questions and up to 20 reading passages.

In the top card, configure quiz metadata:

  • Title (required, max 200 characters)
  • Subject (optional, max 100 characters — used for search in the Quiz Library)
  • Description (optional, max 1,000 characters)
  • Show in the library: Toggle on to publish the quiz as public so other teachers can host/duplicate it and students can practice it.

On each question card you can set:

  • Question type (see the 5 types below)
  • Time limit: 10, 20, 30, 45, 60, 90, 120, 180, or 300 seconds (API accepts 5–600 seconds)
  • Points: 0, 500, 1000, or 2000 points (API accepts 0–2000; Polls are always 0 points)
  • Image: Click 🖼 Image to upload PNG, JPG, GIF, or WebP up to 2 MB (quota: 500 images per teacher account)
  • Explanation: Shown to students after answering (when answer display is enabled) and during post-game review
  • Rubric criterion: Optional learning outcome or criterion tag (max 120 characters), used to group accuracy in the Results Dashboard
  • Card actions: Move up (↑), move down (↓), duplicate (⧉), or delete (×)

The 5 question types

TypeOptions / InputGrading RuleBest Used For
Multiple choice (single) 2 to 6 options; select 1 radio button as correct Exact single choice match Concept checks, definitions, TOEFL reading questions
Multiple answers (multi) 2 to 6 options; tick 1 or more checkboxes as correct All-or-nothing exact set match Selecting all valid properties or causes
True / False (tf) True or False Exact boolean match Quick misconception checks
Short answer (text) Up to 10 accepted answers separated by semicolons (;) Case-insensitive; extra whitespace collapsed Vocabulary, formulas, dates, acronyms (e.g. SRGI2013; SRGI 2013)
Poll (poll) 2 to 6 options; no correct answer Ungraded (0 points); shows live class distribution Icebreakers, opinions, confidence checks

Fast authoring: Paste many questions

If you already have questions in a document or notes, click Paste many questions at the bottom of the editor. Separate each question with a blank line:

  • First line = question text (leading numbers like 1. or 1) are stripped automatically).
  • Following lines = options (leading a., b), -, or • are stripped automatically).
  • Prefix correct option(s) with *.
  • 1 starred option → Multiple choice. 2+ starred options → Multiple answers. 0 starred options → Poll.
  • Exactly two options True / False (or Benar / Salah) with one * → True / False.
  • Lines starting with = → Short answer (multiple = lines add accepted variants).
text
1. One UTM zone has a width of...
a. 3 degrees of longitude
*b. 6 degrees of longitude
c. 10 degrees of longitude

2. Which statements are true about the Mercator projection?
*a. Preserves local angles (conformal)
*b. Exaggerates area near the poles
c. Has zero area distortion worldwide

3. A 1:25,000 map shows more detail than a 1:50,000 map.
*True
False

4. What is Indonesia's national geodetic datum?
= SRGI2013
= SRGI 2013

5. Which topic should we review next week?
- Map projections
- Remote sensing bands
- GNSS positioning

Reading passages (TOEFL Reading style)

Quiz Platform includes dedicated support for reading comprehension:

  1. Add a passage

    In the quiz editor, scroll to Reading passages and click + Passage. Enter an optional title and paste the passage text (up to 20,000 characters; separate paragraphs with blank lines). A live word counter helps gauge length.

  2. Attach questions to the passage

    Either pick the passage from the dropdown on each question card, or click Use for questions without a passage on the passage card to attach it to all unassigned questions at once.

  3. How students experience it

    When a live game or assignment reaches the first question of a passage, the passage is shown first with no countdown running. In a live game, the teacher clicks ▶ Start the questions when the class is ready; in an assignment, the student clicks Start the questions. The passage then stays pinned beside every attached question.

Shuffling respects passage blocks

Even when Shuffle question order is enabled, questions belonging to the same reading passage stay grouped together in their original sequence so paragraph references stay coherent.

AI Question Writer

If your administrator has configured an AI API key, click ✨ Write with AI on the Dashboard or inside the quiz editor to draft questions directly from your teaching material.

  1. Provide teaching material

    Paste text (minimum 200 characters, up to 60,000 characters) or click 📄 Upload material to extract text from PDF, DOCX, PPTX, TXT, or MD files up to 50 MB. You can upload multiple files to append their text.

  2. Choose standard mode or Reading practice mode

    Tick Reading practice (TOEFL Reading style) if the uploaded/pasted text is a passage students will read during the quiz. The AI will attach it as a Reading Passage and generate TOEFL-style multiple-choice questions (factual, negative factual, inference, vocabulary in context, reference, rhetorical purpose, and main idea).

  3. Optional: Add an assessment rubric

    In standard mode, paste or upload a rubric / test blueprint / learning outcomes (up to 20,000 characters). The AI aligns questions to each criterion according to its weights and tags every question's Rubric criterion field so your Results Dashboard shows per-criterion class accuracy.

  4. Set count, difficulty, language, types & extra guidance

    Choose 5 to 25 questions, difficulty (Easy, Medium, Hard), question language (Bahasa Indonesia or English), allowed types, and optional focus notes (e.g. "focus on map projections").

  5. Review before saving

    Click ✨ Write questions (usually takes ~30–60 seconds). Every AI-drafted question goes through the same validation as manual questions and has its option positions randomized. Nothing is saved until you review, edit if needed, and click Save.

AI rate limits & scanned PDFs

  • Each teacher account is limited to 5 AI requests per 5 minutes and 40 per day.
  • Scanned image-only PDFs contain no selectable text and cannot be extracted — run OCR first or paste text directly.
  • Only teaching material (never student data) is sent to the configured AI provider.

Import & Export JSON

You can back up, version-control, or share quizzes between servers as JSON files:

  • Export: Open a quiz page (click the quiz card title on Dashboard) and click Export JSON to download quiz-<id>.json.
  • Import: On the Dashboard, click Import JSON and pick a .json file. It creates a new quiz and opens it in the editor.
json
{
  "title": "Basic Cartography",
  "subject": "Cartography",
  "description": "Scale, projections, contours, and symbols.",
  "passages": [
    {
      "title": "Map Scale Overview",
      "text": "First paragraph...\n\nSecond paragraph..."
    }
  ],
  "questions": [
    {
      "type": "single",
      "text": "On a 1:50,000 map, 1 cm represents...",
      "options": ["50 m", "500 m", "5 km", "50 km"],
      "answer": 1,
      "time": 30,
      "points": 1000,
      "explanation": "1 cm x 50,000 = 50,000 cm = 500 m.",
      "criterion": "Scale calculations",
      "passage": 0
    },
    {
      "type": "tf",
      "text": "1:25,000 is a larger scale than 1:50,000.",
      "answer": true,
      "time": 20,
      "points": 1000
    },
    {
      "type": "multi",
      "text": "Which properties apply to the Mercator projection?",
      "options": ["Conformal", "Polar area distortion", "Zero area distortion"],
      "answer": [0, 1],
      "time": 45,
      "points": 1000
    },
    {
      "type": "text",
      "text": "Indonesia's national datum?",
      "answer": ["SRGI2013", "SRGI 2013"],
      "time": 30,
      "points": 1000
    }
  ]
}

Duplicating quizzes for different classes

Teaching the same material to Class A and Class B? Click Duplicate on a quiz and name the copy (e.g. Basic Cartography (Class B)). Each copy gets its own ID, games, and reports, and edits never affect the original.
