Live Quizzes, Assignments & Anti-Cheat

Run real-time classroom games on a projector, assign self-paced homework with deadlines, enable anti-cheat protection, analyze results dashboards, review answers, and spin the wheel.

Game modes & launch settings

Click ▶ Host on any quiz to open the launch dialog. Choose between two modes and configure per-game options:

Hosting a live quiz

  1. Project the lobby

    After clicking Start, the host screen displays the site URL, a large 6-digit game code, and a QR code. Click ⛶ in the top-right bar for fullscreen presentation.

  2. Manage players in the lobby

    Names appear live as students join (up to 500 players per game). Click any player's name chip to remove (Remove) an inappropriate nickname.

  3. Run questions & reveals

    Click ▶ Start to launch the first question (or the Reading screen if the question has a passage). The question closes automatically when the timer expires or when every connected player has answered — or click Close question early. On reveal, the projector shows the answer distribution bar chart (or word cloud for short answers), the explanation, and the Top 5 leaderboard.

  4. Finish the session

    After the last question, click Final results → to display the podium with quick links to ▤ Results dashboard, ▶ Review questions, and ◔ Spin the wheel.

Resilient connections

Both host and student screens automatically reconnect over WebSocket if Wi-Fi blips. Every submitted answer is written immediately to SQLite.

How scoring works

Correct answers earn points based on each question's configured points value (default 1,000):

  • Timed questions (all Live quizzes, and timed Assignments): An instant correct answer scores 100% of the question's points, sliding linearly down to 50% at the time limit:
    score = round(points × (1 − 0.5 × elapsed_ms / limit_ms))
    Example: For a 1,000-point, 30-second question, answering correctly in 6 seconds earns round(1000 × (1 − 0.5 × 0.2)) = 900 pts; answering right before 30 seconds earns 500 pts.
  • Untimed Assignments: Every correct answer earns 100% of the question's points regardless of speed.
  • Incorrect, unanswered, or Poll questions: 0 pts.

Running self-paced assignments

When you start an Assignment, you are taken straight to its Results dashboard, which displays the shareable 6-digit code, QR code, and Copy link button (https://your-site/join/123456).

  • Students can open the assignment anytime before the deadline.
  • If per-question timers are enabled, the clock starts when a student opens a question — reloading the page does not reset the timer.
  • The Results Dashboard auto-refreshes every 10 seconds while the assignment is open.
  • Click End at any time to close submissions manually.

Anti-cheat mode

Enable 🛡 Anti-cheat mode in the launch dialog when running graded quizzes or exams.

What it detects & enforces

  • Tab / app switching & screen lock (visibilitychange / blur) and exiting fullscreen on desktop browsers.
  • 2-second grace period: Brief accidental glitches or notifications shorter than 2.0 s are logged but not counted as violations.
  • Copy, cut, paste, and right-click context menu are blocked on the quiz page.
  • Server-side record: All exits are stored on the server immediately, so refreshing the page does not clear a student's record.
  • Transparent notice: Before the first question opens, students see the exact anti-cheat rules and must click I understand, start.

Three penalty levels

PenaltyBehavior
Record only (record) Logs every counted exit and total seconds away, alerts the host live, and displays the count & affected question numbers in the Results Dashboard and CSV export.
Zero points for open question (zero) Any question open while the student leaves the page for ≥ 2 seconds automatically scores 0 points, even if answered correctly.
Lock out after N exits (lock) After 1–10 counted exits (default 3), the student is locked out and cannot submit answers until the teacher clicks Unlock (either from the live corner alert box on the host screen or from the Results Dashboard table). Once unlocked, the counter toward the next lock starts fresh while total exits stay recorded.

Be transparent about limitations

A browser can detect leaving the page, but cannot lock down the operating system or detect a second phone/device. Combine anti-cheat mode with shuffled questions/options, sensible timers, and classroom supervision.

Results dashboard & CSV export

Open any game's Report from the Dashboard (or after a live game ends) to see:

  • Winner banner & Top 3 podium with score, correct count, and average response time.
  • Class summary metrics: Total players, average accuracy %, average score, top score, completion count, and average answer time.
  • Spread of accuracy histogram: Number of students in each 20% accuracy band (0–20% through 80–100%).
  • Automatic highlights: Hardest question, easiest question, and students scoring below 50% who may need support.
  • Student performance table: Full ranking with score, correct/wrong/blank counts, accuracy badge, average time, anti-cheat exits (plus 🔒 Unlock button if locked), and a per-question ✓ / ✗ / · matrix.
  • Performance by rubric criterion: Shown automatically when questions have rubric criteria attached.
  • Question performance table & expandable answer breakdown: Accuracy bar, response count, average time, most common wrong answer, and per-option bar charts.
  • Export & Print: Click ⬇ CSV (UTF-8 with BOM for clean Excel import, plus automatic formula-injection sanitization) or 🖨 Print / PDF.

Post-game review mode

Click ▶ Review questions from the podium or Results Dashboard to walk through the finished quiz question-by-question on the classroom projector without replaying it.

  • Color-coded question number dots at the top show class performance at a glance (green ≥ 70%, amber 40–69%, red < 40%).
  • The correct answer starts hidden so you can discuss each question with the class first, then reveal the answer key, class distribution, and explanation.
  • Keyboard shortcuts: ← / → (or PageUp / PageDown) switch questions; Space or Enter toggles showing/hiding the answer.

Spin the wheel

Open Spin the wheel from the top menu (or click ◔ Spin the wheel inside any live lobby or report to pre-fill it with that game's players).

  • Manual entries: Type one entry per line (2 to 200 entries). Use number | name (e.g. 12 | Ani Wijaya) so the wheel displays compact numbers on the slices while the winner dialog announces the full student name!
  • Upload Excel / CSV: Click ⬆ Upload Excel / CSV to load a 2-column .xlsx or .csv class list (column 1 = number/NIM/attendance no., column 2 = name; headers like No, Nama are skipped automatically). Click Download a sample to get a ready-to-edit CSV template.
  • After a spin: Choose Keep on the wheel or Remove from the wheel so the same student isn't picked twice.
  • Save wheels: Signed-in users can save up to 200 wheels to reuse across classes.
