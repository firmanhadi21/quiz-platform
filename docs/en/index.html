Getting Started

Overview

Quiz Platform is a self-hosted classroom quiz application with live projector games, self-paced assignments, an AI question writer, anti-cheat monitoring, rich results dashboards, and a spin-the-wheel picker — with a full Bahasa Indonesia and English interface.

What Quiz Platform is

Quiz Platform is built for schools, university departments, training centers, and individual teachers who want an interactive classroom quiz tool that runs on their own server — keeping student names, scores, and teaching material under their own control.

It ships as one lightweight Docker container powered by FastAPI, SQLite (WAL mode), and plain vanilla JavaScript with zero frontend build step. One small server (1 CPU, 1 GB RAM) easily handles a school or department with a few hundred simultaneous players.

Key features

▶

Live Quizzes

6-digit code and QR code per game. Teachers present on the class screen while students answer on phones. Faster correct answers earn higher speed-bonus points.

✎

Self-Paced Assignments

Run the same quizzes asynchronously with optional per-question timers, deadlines, and per-student shuffling of questions and options.

✨

AI Question Writer

Paste notes or upload PDF, DOCX, PPTX, or TXT (up to 50 MB), optionally with an assessment rubric. Works with any OpenAI-compatible API (DeepSeek, OpenAI, OpenRouter).

📖

Reading Passages

Built for TOEFL-style reading comprehension: students read the passage first with no timer running, then keep it open side-by-side next to every question.

🛡

Anti-Cheat Mode

Optional per game. Detects leaving the tab/app or exiting fullscreen (after a 2-second grace period), blocks copy/paste, and supports Record, Zero-point, or Lock-out penalties.

▤

Results & Review

Winner podium, accuracy spread histogram, hardest/easiest questions, per-student matrix, rubric-criterion accuracy, CSV export, print/PDF, and step-by-step review.

◔

Spin the Wheel

Pick students or topics randomly. Type entries, load players directly from a game, or upload an Excel (.xlsx) / CSV class roster (number & name).

⚙

Roles & Branding

Student, Teacher, and Admin roles. Admins manage accounts, registration policy, site name, organization, primary/accent colors, and custom logo directly from the web UI.

Known limits & design trade-offs

  • Single process + SQLite: Designed for one school, faculty, or department (a few hundred concurrent players; up to 500 players per game). Live game turn state lives in memory, so always run with --workers 1.
  • No outbound email: Password resets are handled directly by an Admin (via the Admin page or manage.py reset-password), which generates a one-time temporary password.
  • Browser-based anti-cheat: Anti-cheat records leaving the quiz tab/app or fullscreen and blocks copy/paste, but a browser cannot physically prevent switching apps or detect a second device.
